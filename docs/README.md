# Slide 2 : Lagrangian simulation for El Niño 2026

- Particles released in Niño 3.4 region and tracked backward in time  for one year.
- They follow 2D surface currents based on GLORYS12 version 1 monthly data.
- Most particles come from western Pacific (warm pool) and few from Eastern Pacific (cold tongue).
- Along equator is westward flow. Off-equator is eastward flow.
- Meridional velocity is generally smaller than zonal velocity.
